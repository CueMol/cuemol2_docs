## PukiWiki 정보

*   PukiWiki는 웹마스터뿐만 아니라 방문자도 아무런 제한 없이 모든 페이지를 수정할 수 있는 웹 기반 도구입니다.
*   방문자가 메시지를 남길 수 있다는 점에서는 일반 게시판과 유사할 수 있습니다.
*   그러나 게시판은 메시지를 남기는 것만 가능한 반면, PukiWiki는 메시지를 남기는 것뿐만 아니라 기존 페이지의 전체 디자인과 내용을 변경할 수 있습니다.
*   PukiWiki는 유키 히로시(Mr. Hiroshi Yuki) 님이 만든 YukiWiki를 기반으로 한 독창적인 위키 엔진입니다.
*   sng 님이 PukiWiki 1.3 릴리스까지 개발을 지속하였고, 1.3.1b 이후에는 PukiWiki 개발팀이 개발을 이어받았습니다.
*   현재는 PukiWiki라는 이름으로 YukiWiki에서 독립하여 기능이 지속적으로 강화되고 있습니다.
*   현재 기능은 다음과 같이 요약할 수 있습니다:
```
PukiWiki = (YukiWiki + Tiki + RWiki) / 3
```
*   "플러그인"을 추가하여 기능을 자유롭게 확장할 수 있습니다.
*   PukiWiki 패키지에 기본 포함된 표준 플러그인 외에도 수많은 오리지널 플러그인이 존재합니다.
