## 라이선스 정보 (Licence)

**CueMol**은 자체 개발된 고유 코드와 더불어 아래의 오픈소스 라이브러리 및 도구를 사용하고 있습니다:

* [Mozilla XULRunner](https://developer.mozilla.org/ja/docs/XULRunner)
* [FFTW](http://www.fftw.org)
* [POV-Ray](http://www.povray.org)
* SSM superpose (Superpose based on Secondary Structure Matching)
* [BALL](http://www.ball-project.org/)
* [PCRE](http://www.pcre.org)
* [Expat XML Parser](http://expat.sourceforge.net/)
* CGAL (Computational Geometry Algorithms Library)
* Boost C++ Libraries
* Little CMS
* GLEW (OpenGL Extension Wrangler Library)
* zlib
* libpng

각 라이브러리 및 모듈은 해당 소프트웨어의 원본 라이선스 규정을 따릅니다.

## 외부 연동 소프트웨어 안내

CueMol의 모든 고급 기능(정전기 전위 계산, 고품질 렌더링 등)을 최대한 활용하기 위해 다음의 외부 소프트웨어가 함께 사용됩니다. 배포 편의를 위해 제공되는 사전 컴파일된 바이너리는 각 소프트웨어 고유의 라이선스를 준수합니다:

* **APBS**: [http://www.poissonboltzmann.org/apbs](http://www.poissonboltzmann.org/apbs)
* **PDB2PQR**: [http://www.poissonboltzmann.org/pdb2pqr](http://www.poissonboltzmann.org/pdb2pqr)
* **POV-Ray**: [http://www.povray.org/](http://www.povray.org/)
