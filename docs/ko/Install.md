## 설치 안내 (Installation)

구버전 CueMol1의 설치에 대해서는 [Install-1.1](../Install-1.1)을 참조하세요.

---

## Windows 버전

### 바이너리 배포판 설치
1. [다운로드](./Download) 페이지에서 Windows용 최신 설치 파일(`cuemol2-X.X.X.X-win64.installer.exe` 또는 zip)을 다운로드합니다.
2. 다운로드한 설치 프로그램을 실행합니다.
3. 설치 마법사의 안내에 따라 **Next** 버튼을 클릭하여 설치를 완료합니다.

#### 설치 전 주의 사항
* 이전 버전의 CueMol2가 이미 설치되어 있는 경우 자동으로 덮어쓰며 업데이트됩니다.
* 구버전 CueMol 1(1.1 계열)과는 별개의 프로그램으로 설치되므로 서로 충돌하지 않고 동시에 사용할 수 있습니다.
* 프로그램 제거는 **제어판 &gt; 프로그램 및 기능 (또는 Windows 설정 &gt; 앱)**에서 수행할 수 있습니다.

> [!WARNING] 토폴로지(Topology) 파일 백업
> 아미노산/핵산 등의 토폴로지 정의 파일을 직접 수정하거나 커스터마이징하여 사용 중인 경우, 재설치 시 기본 파일로 덮어씌워질 수 있습니다. 설치 전에 수정된 파일을 안전한 곳에 백업한 뒤, 설치 완료 후 다시 복사하시기 바랍니다.

#### 사용자 프로필 및 환경설정 폴더
창 위치, 패널 배치, 사용자 설정 등은 프로그램 본체와 별개로 아래의 프로필 디렉터리에 저장됩니다. 따라서 프로그램을 재설치하거나 삭제해도 프로필 정보는 유지됩니다.

* **Windows 10 / 11 / 7 / Vista**:
  ```
  C:\Users\<사용자명>\AppData\Roaming\BKR-LAB\CueMol2_GUI
  ```
* **Windows XP**:
  ```
  C:\Documents and Settings\<사용자명>\Application Data\BKR-LAB\CueMol2_GUI
  ```

> [!TIP] 비정상 종료 및 실행 오류 문제 해결
> CueMol2가 실행 중 비정상적으로 종료(Crash)되거나 화면 레이아웃이 깨지는 등 오작동하는 경우, **CueMol2를 완전히 종료한 후 위 `CueMol2_GUI` 폴더를 삭제**하고 다시 실행해 보세요. 새로운 기본 설정으로 깨끗하게 초기화됩니다.

### 소스 코드에서 빌드
GitHub 저장소의 소스 코드를 통해 직접 컴파일할 수 있습니다. 자세한 내용은 GitHub 소스 저장소 빌드 문서를 참조하세요.

## macOS 버전

### 바이너리 배포판 설치
1. [다운로드](./Download) 페이지에서 macOS용 `.dmg` 디스크 이미지 파일을 다운로드합니다.
2. 다운로드한 `.dmg` 파일을 더블 클릭하여 엽니다.
3. 표시되는 창에서 **CueMol2.app** 아이콘을 시스템의 **응용 프로그램(Applications)** 폴더로 드래그 앤 드롭하여 복사합니다.

### Gatekeeper 보안 및 "손상된 파일" 오류 해결
최신 macOS에서는 공증(Notarization)되지 않은 앱을 처음 실행할 때 다음과 같은 경고 메시지가 나타날 수 있습니다:
> *"CueMol2이(가) 손상되었기 때문에 열 수 없습니다. 해당 항목을 휴지통으로 이동해야 합니다."*

이는 macOS의 격리(Quarantine) 확장 속성으로 인한 현상이며, 터미널(Terminal) 앱에서 아래 명령어를 실행하여 격리 속성을 제거하면 정상적으로 실행할 수 있습니다:

```bash
xattr -cr /Applications/CueMol2.app/
```

*(필요 시 시스템 설정 &gt; 개인정보 보호 및 보안에서 '확인 없이 열기'를 클릭하여 승인할 수도 있습니다.)*

### 사용자 설정 및 프로필 폴더
macOS에서 패널 배치 및 프로그램 설정은 다음 경로에 저장됩니다:

```
/Users/<사용자명>/Library/Application Support/CueMol2_GUI
```

> [!TIP] 오작동 시 설정 초기화
> macOS에서 CueMol2가 충돌하거나 실행되지 않을 경우, CueMol2를 종료한 상태에서 위 `CueMol2_GUI` 폴더를 삭제한 후 프로그램을 다시 시작하시기 바랍니다.
