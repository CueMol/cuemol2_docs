## 버전별 업데이트 내역 (Release Notes)

CueMol의 버전별 주요 변경 사항 및 업데이트 내역입니다. 각 OS별 설치 파일은 [다운로드](./Download) 또는 [GitHub Releases](https://github.com/CueMol/cuemol2/releases/)에서 확인하실 수 있습니다.

---

### 버전 2.3 시리즈
버전 2.3 이후의 상세 릴리스 노트는 [GitHub Releases](https://github.com/CueMol/cuemol2/releases/) 페이지에 지속적으로 업데이트됩니다.

* **2.3.0.461 (2025/11/4)**: 최신 릴리스 및 안정화 패치
* **2.3.0.460 (2025/8/14)**: 최신 릴리스
* **2.3.0.454 (2025/1/16)**: UI 개선 및 버그 수정

---

### 버전 2.2.3 시리즈

#### 버전 2.2.3.443 (2019/1/14)
* SDF 형식 저분자 리더 구현
* MOL2 형식 저분자 리더 구현
* PDB 가져오기 메뉴에서 열린 렌더러 선택 대화상자에 복합 렌더러가 표시되지 않던 버그 수정
* SSM 구조 중첩(ssm-superpose) 실행 후 원자를 클릭할 수 없게 되던 문제 수정

#### 버전 2.2.3.437 (2018/6/8)
* 외곽선(Edge lines)이 속한 삼각형 모서리의 색상에 따라 반투명해지도록 개선 (외곽선이 적용된 리본 및 카툰 모델의 "세그먼트 끝단 페이드아웃" 지원)
* "Mol Superpose" 대화상자의 자동 중심 재설정(auto-recenter) 체크박스 동작 오류 수정

#### 버전 2.2.3.434 (2018/5/8)
* macOS 릴리스에 APBS 및 PDB2PQR 바이너리 기본 번들 포함
* isosurf 및 molsurf 렌더러를 위한 멀티 그래디언트 색상 지정(Multi-gradient coloring) 구현 및 전용 GUI 추가
* MTZ 파일 리더 대화상자에서 FFT 그리드 간격을 임의 수치로 지정할 수 있는 옵션 추가
* 여러 교차 평면으로 자를 수 있도록 분자 표면 절단 도구(Mol surface cutter) 개선
* isosurf 렌더러의 MolSurf 객체 생성기가 닫힌 경계(closed boundary) 메시를 생성하도록 개선
* symm 렌더러에 렌더링할 최대 대칭 연산자 수를 제한하는 `maxop` 속성 추가
* 스칼라 필드 객체에 대한 줌인 동작 구현
* 맵 렌더러의 주기적 경계 조건(PBC) 옵션 변경용 GUI 구현
* 메시 및 isosurf 렌더러에 절대값 기준 등고선 레벨(Contour level) 설정 기능 추가
* 분자 선택 위젯 기본 동작 개선
* **버그 수정**:
    * POV-Ray 렌더링 대화상자를 닫은 후 투영 유형 등 렌더링 설정이 저장되지 않던 문제 수정
    * 다중 뷰 모드에서 한 뷰를 삭제한 후 OpenGL 셰이더를 사용하는 렌더러가 표시되지 않던 문제 수정
    * CueMol에서 생성된 자식 프로세스가 `LD_LIBRARY_PATH` 등 환경 변수를 상속하지 않던 문제 수정

#### 버전 2.2.3.430 (2018/2/6)
* 다양한 분자 편집(Molecular Editor) 기능 구현:
    * 체인 이름 변경 (Rename Chain)
    * 잔기 번호 변경 (Renumber Residues)
    * 선택된 원자 삭제 (Delete Selected Atoms)
    * 분자 객체 간 병합 (Merge Molecules)
* PDB 가져오기 GUI에서 PDB 및 전자 밀도 맵의 다운로드 서버 선택 옵션 추가
* isosurf 렌더러의 최대 범위(max extent) 설정 GUI 추가 및 동작 수정
* **버그 수정**:
    * 워크스페이스 패널에서 다중 렌더러 복사가 정상 작동하지 않던 문제 수정
    * PyMOL 1.7.6 이상에서 저장된 PSE 파일을 불러오지 못하던 문제 수정
    * mapmesh 렌더러의 `bufsize` 변경 시 밀도 맵 패널의 최대 범위 수치가 갱신되지 않던 문제 수정
    * MapSurfRenderer의 POV-Ray 렌더링 시 노이즈 점이 발생하던 문제 수정
    * MapSurfRenderer의 OpenGL 엣지 렌더링 미리보기가 어긋나던 문제 수정
    * 씬 파일(`.qsc`)에 임베드된 분자에 대해 `xformMat` 속성이 적용되지 않던 문제 수정
    * PDB 로드 후 서열 패널 내용이 갱신되지 않던 문제 수정
    * 새 애니메이션 객체의 기본 지속 시간이 0이 되던 문제 및 슬라이더 오작동 수정

#### 버전 2.2.3.422
* 대칭 분자(Symmetry mates) 생성 시 충돌하던 문제 수정

#### 버전 2.2.3.421
* 밀도 패널에 "단위포 표시(Show unit-cell)" 버튼 추가
* 대형 고분자 지원을 위해 RCSB 서버에서 좌표 파일을 mmCIF 형식으로 다운로드하도록 변경
* 애니메이션 정밀도 향상을 위해 내부 시간 단위를 나노초로 변경
* atomintr 렌더러(거리 측정선)에서 시작/끝 캡 스타일을 개별 지정할 수 있도록 지원
* 서열 패널에서 아미노산 서열을 텍스트로 복사하는 기능 추가
* ballstick 원기둥의 엣지 렌더링 미리보기 구현
* 불투명 외곽선과 반투명 표면의 자연스러운 블렌딩 지원
* **버그 수정**: APBS 외 생성 OpenDX 파일 로드 오류, 서열 패널 체인 표시 순서 오류, 복수 파일 드래그앤드롭 오류 등 해결

#### 버전 2.2.3.412
* dsurface(밀도 서피스) 렌더러 개선: 뒷면 표시 옵션, 정전기 전위 색상 매핑 모드 및 `ramp-above` 속성 추가
* 카툰 렌더러에서 헬릭스 사이의 불필요한 미세 코일 세그먼트 제거 옵션 추가
* 선택 영역 변경 시 선택 렌더러 자동 생성
* gpu_mapmesh 렌더러에서 투명도 및 선 두께 조절 지원
* 원자 선택(Picking) 루틴 정밀도 향상
* 전자 밀도 맵 다운로드 소스를 EBI 서버로 전환
