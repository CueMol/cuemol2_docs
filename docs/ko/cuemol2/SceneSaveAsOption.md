## 씬 저장 옵션 (Scene Save Options)

CueMol2에서 **File &gt; Save scene as...**를 통해 씬(`.qsc`)을 새 이름으로 저장할 때 다음과 같은 세부 옵션 대화상자가 표시됩니다:

## 1. 객체 임베드 설정 (Object Embedding)

기본적으로 CueMol2는 분자 좌표(PDB)나 표면 데이터가 수정(예: 구조 중첩으로 좌표 이동)된 경우에만 `.qsc` 파일 내부에 데이터를 포함(Embed)하고, 수정되지 않은 원본 파일은 외부 파일 경로 링크로 저장합니다.

그러나 이 상태에서 `.qsc` 파일만 다른 컴퓨터나 폴더로 이동하면 **외부 파일 링크가 깨져 씬이 정상적으로 열리지 않을 위험**이 있습니다.

> [!TIP] Embed all objects 옵션
> **Embed all objects** 체크박스를 켜고 저장하면, 좌표 수정 여부와 상관없이 모든 분자 객체와 표면 데이터가 `.qsc` 파일 내부에 완전히 포함되어 저장됩니다. 파일을 다른 사람에게 전달하거나 다른 PC로 옮길 때는 이 옵션을 켜는 것을 강력히 권장합니다.

*(주의: 일부 대용량 전자 밀도 맵 등은 파일 크기 관리를 위해 링크 형태로 유지될 수 있으므로 원본 맵 파일도 함께 보관하세요.)*

---

## 2. 파일 버전 및 인코딩 (File Version)

* **QDF0**: 표준 호환 포맷으로, 모든 구버전 CueMol2에서도 호환되어 열립니다.
* **QDF1**: 최신 확장 포맷으로, 압축 및 고속 입출력을 지원합니다.

### 세부 옵션
* **Enable text encoding**: 내장된 객체 데이터를 Base64로 텍스트 인코딩하여 저장합니다. 텍스트 편집기(VS Code 등)로 `.qsc` 파일을 직접 열어보고 수정할 계획이 있다면 이 옵션을 켜는 것이 좋습니다. (파일 용량은 약 4/3배 증가합니다.)
* **Enable compression**: 데이터를 GZIP으로 압축하여 저장합니다. 파일 용량을 크게 줄여 디스크 공간을 절약하고 전송 속도를 높입니다.
