## 색상 지정 문법 (Color Syntax)

CueMol2에서는 색상 선택 위젯(Color Palette)을 통한 시각적 지정뿐만 아니라, 색상 입력 텍스트 상자에 문자열 코드를 직접 입력하여 정밀하게 색상을 정의할 수 있습니다.

---

## 1. HTML 16진수 표기법

HTML 및 CSS 표준과 동일한 `#` 16진수 표기법을 지원합니다.

### 6자리 표기법: `#RRGGBB`
* `RR`: Red (00 ~ FF)
* `GG`: Green (00 ~ FF)
* `BB`: Blue (00 ~ FF)

```css
#1234AB  /* Red=18, Green=52, Blue=171 */
#FFFFFF  /* White (흰색) */
#FF0000  /* Red (빨간색) */
```

### 3자리 단축 표기법: `#RGB`
* `#XYZ`는 `#XXYYZZ`와 동일합니다.

```css
#CCC     /* #CCCCCC (밝은 회색) */
#F00     /* #FF0000 (빨간색) */
```

---

## 2. RGB / RGBA 표기법

0.0에서 1.0 사이의 실수값으로 각 채널의 강도를 지정합니다.

* **`rgb(R, G, B)`**: 
  ```css
  rgb(1.0, 0.5, 0.5)  /* 연분홍색 */
  ```
* **`rgba(R, G, B, A)`**: 불투명도(A; 1.0=불투명, 0.0=완전 투명)를 포함합니다.
  ```css
  rgba(0.0, 1.0, 0.0, 0.5)  /* 50% 반투명 초록색 */
  ```

---

## 3. HSB / HSBA 표기법

색상(Hue), 채도(Saturation), 명도(Brightness) 기반의 직관적인 색상 지정 방식입니다.

* **`hsb(H, S, B)`**:
  * `H`: 색상 각도 (0 ~ 360; 0=Red, 120=Green, 240=Blue 등)
  * `S`: 채도 (0.0 ~ 1.0)
  * `B`: 명도 (0.0 ~ 1.0)
* **`hsba(H, S, B, A)`**: 불투명도(A)를 포함합니다.

---

## 4. 이름 표기법 (Named Colors)

시스템 스타일 파일에 정의된 표준 색상 이름을 대소문자 구분 없이 직접 입력할 수 있습니다. W3C SVG/CSS3 표준 색상 이름(예: `antiquewhite`, `cyan`, `gold`, `navy` 등)을 모두 지원합니다.

```css
antiquewhite  /* #faebd7 과 동일 */
deepskyblue   /* #00bfff 와 동일 */
```

---

## 5. 분자 마스터 색상 표기 (`$molcol`)

```css
$molcol
```

렌더러 자체의 고정 색상 대신, 해당 렌더러가 속한 **모체 분자 객체(MolCoord)에 정의된 마스터 컬러링 규칙**을 참조하여 자동으로 채색합니다.

---

## 6. 색상 수식어 (Modifiers)

기본 색상 표기 뒤에 중괄호 `{ key: value; ... }` 구문을 추가하여 재질, 투명도, 채도/명도 보정을 동적으로 부여할 수 있습니다:

```css
<색상지정>{ <수식어키>: <수식어값>; ... }
```

### 지원되는 수식어 키
* **`material`**: 질감/재질 지정 (예: `shiny`, `diffuse`, `shadow` 등)
* **`alpha`**: 불투명도 강제 지정 (`0.0 ~ 1.0`)
* **`mod_h`**: 색상(Hue) 가감 변조
* **`mod_s`**: 채도(Saturation) 가감 변조 (`-1.0 ~ 1.0`)
* **`mod_b`**: 명도(Brightness) 가감 변조 (`-1.0 ~ 1.0`)

### 수식어 활용 예시
```css
/* 빨간색에 음영 없는 플랫 재질(shadow)과 50% 투명도 적용 */
rgb(1, 0, 0){ material: shadow; alpha: 0.5 }

/* 분자 기본 색상에서 채도를 0.2 낮춰 부드러운 파스텔 톤으로 표현 */
$molcol{ mod_s: -0.2 }
```
