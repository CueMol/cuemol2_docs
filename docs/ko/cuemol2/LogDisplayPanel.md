## 로그 표시 패널 (Log Display Panel)

CueMol2의 작업 수행 내역, 로드된 분자 파일 정보, POV-Ray 및 FFmpeg 렌더링 메시지, 스크립트 출력 및 시스템 에러 로그가 실시간으로 출력되는 패널입니다.

상단 메뉴의 **Window &gt; Panels &gt; Log**를 통해 패널을 표시하거나 숨길 수 있습니다.

---

### 주요 기능
* **시스템 정보 확인**: CueMol 시작 시 OpenGL 버전, GPU 드라이버 및 GLSL 지원 정보 확인
* **작업 진행 상황 모니터링**: PDB 다운로드, 전자 밀도 맵 FFT 계산, APBS 정전기 전위 계산 진행 상황 출력
* **오류 디버깅**: 렌더링 실패나 파일 로드 예외 발생 시 원인 분석 및 에러 리포트 작성 지원
