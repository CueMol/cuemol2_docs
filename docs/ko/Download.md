## 다운로드

각 릴리스의 변경 사항은 [릴리스(Releases)](https://github.com/CueMol/cuemol2/releases/)에서 확인할 수 있습니다.

다운로드 후 설치 방법은 [설치(Install)](./Install) 페이지를 참조하세요.

### CVS 저장소
다음과 같이 익명 사용자로 CueMol 1.1의 CVS 저장소에 접근할 수 있습니다.
```bash
cvs -d:pserver:anonymous@cvs.sourceforge.jp:/cvsroot/cuemol login 
cvs -z3 -d:pserver:anonymous@cvs.sourceforge.jp:/cvsroot/cuemol co cuemol
```
